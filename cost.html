Cost of generating a video

There are three ways to run this workflow — the Google Flow UI, fal.ai's hosted models, or the Gemini API directly — and each bills differently. Rates change often, so this page tracks what's known from this project plus live links to each provider's pricing, alongside a calculator you can plug current rates into.

Google Flow (used here)

This project's output video was generated in the Flow UI with Veo 3.1 - Lite:

  • 10 credits for one 8-second video
  • Credits are drawn from a Google AI / Flow subscription plan

See labs.google/fx/tools/flow and the current Google AI plans for what a credit costs on your plan.

fal.ai (API, Option A)

Pay-as-you-go per generation; price depends on the model chosen (e.g. Kling, Luma Ray2, Veo on fal) and output length/resolution.

  • No subscription required — billed per call
  • Price varies by model, not by "credits"

See fal.ai/pricing and each model's page under fal.ai/models for the current per-generation rate.

Gemini API / Veo (Option B)

Usage-based pricing, typically per second of generated video, billed to your Google Cloud / AI Studio account.

  • No Flow-style credits — straight usage billing
  • Rate depends on the Veo model version used

See ai.google.dev/gemini-api/docs/pricing for current per-second/per-generation rates.

Prices are intentionally not hardcoded on this page beyond the one figure this project actually used (10 Flow credits) — provider rates change frequently. Use the calculator below with numbers copied from the links above.
